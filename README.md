## Why does this even exist?

I can stand boilerplate to an extent. However, I am not writing 4
different navbars for each page. As such, I had to bring PHP into this.
Furthermore, it was supported on my envs pubnix so I just deployed it
there. [See it in action!](https://amadaluzia.envs.net)

## How to serve locally

You must install:

- php (8.4)

```console
$ php -S 127.0.0.1:8000
```

## How to hack

You must install:

- nodejs
- npm

```console
$ npm install
```

Read `package.json` for possible commands. :)
